# Maintainers

This file lists the current maintainers of NVKE. Maintainers have write
access to the repository and share responsibility for reviews, releases,
and project direction.

See [GOVERNANCE.md](GOVERNANCE.md) for the full governance model,
including how maintainers are added and removed.

Names and affiliation come from the NVIDIA directory, resolved through the
GitHub-to-SSO mapping. Everyone listed was an active employee when this was
written. Anyone listed can correct their own row.
