# Support

## How to get help

| Channel | When to use |
|---|---|
| [GitHub Issues](https://github.com/dsx-ai-factory/nvke/issues) | Bug reports, feature requests, and documentation gaps |
| [GitHub Discussions](https://github.com/dsx-ai-factory/nvke/discussions/categories/q-a) | Questions, design proposals, and general Q&A |
| [`#nvke` on the DSX AI Factory Slack](https://inviter.co/dsx-ai-factory) | Chat and quick questions; the link is an invite |

## Before opening an issue

1. Search [existing issues](https://github.com/dsx-ai-factory/nvke/issues) to avoid duplicates.
2. Check the [documentation](docs/) and the module-level `README.md` files under `controller/` and `agent/`.
3. Reproduce the problem on the latest commit of `main`.

## Security vulnerabilities

Do **not** open a public issue for security vulnerabilities. Follow the
process described in [SECURITY.md](SECURITY.md).

## Community

We welcome contributions. See [CONTRIBUTING.md](CONTRIBUTING.md) for the
full guide, including how to set up your development environment and
submit a pull request.

## NVIDIA enterprise support

For users running NVKE as part of a supported NVIDIA product, contact your
NVIDIA support representative or visit the
[NVIDIA Support Portal](https://www.nvidia.com/en-us/support/).
