# cluster-api-provider-provisioned

A Cluster API infrastructure provider for hosts that are already provisioned.

Cluster API expects an infrastructure provider to create machines. NKE does not
work that way: the hosts exist before Cluster API is involved, provisioned
through the Forge API or supplied by the operator. This provider is the adapter.
It presents already-provisioned hosts to Cluster API through the contract Cluster
API expects, so the rest of the Cluster API machinery works unchanged.

It builds one binary, `manager`, and runs as a controller in the same cluster as
the Cloud Workflow Engine.

## The types it owns

All in the `infrastructure.cluster.x-k8s.io` group, which Cluster API requires
for an infrastructure provider.

| Kind | What it is |
|---|---|
| `ProvisionedCluster` | The infrastructure side of a Cluster API `Cluster` |
| `ProvisionedMachine` | The infrastructure side of a Cluster API `Machine` |
| `ProvisionedMachineTemplate` | The template a machine deployment stamps machines from |
| `ProvisionedHostClaim` | A claim on a host from the pool of provisioned hosts |

Two controllers reconcile them: `ClusterReconciler` for `ProvisionedCluster` and
`MachineReconciler` for `ProvisionedMachine`.

## Building and testing

```bash
make -C cluster-api-provider-provisioned test
make -C cluster-api-provider-provisioned lint
```

`make help` in the module lists the rest.

## Generated code

The deep-copy implementations, the CRDs and the controller RBAC are generated by
`controller-gen`, which the module pins and installs itself:

```bash
make -C cluster-api-provider-provisioned generate   # deep-copy implementations
make -C cluster-api-provider-provisioned manifests  # CRDs and RBAC
```

Commit what those produce. `generate-check` regenerates and fails if the
committed output differs, so a missed regeneration fails CI rather than being
discovered later.

## Deployment

`config/` holds the kustomize bases for the CRDs, the manager and its RBAC.
`metadata.yaml` declares the release series and the Cluster API contract version,
which is what makes the provider installable with `clusterctl`.

`make docker-build` builds amd64 and arm64 images into a local OCI archive.
