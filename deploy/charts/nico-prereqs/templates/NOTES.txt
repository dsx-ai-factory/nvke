Wait for the database before installing NICo. Its migration Job runs as a
pre-install hook and connects to PostgreSQL immediately:

  kubectl -n {{ .Release.Namespace }} rollout status statefulset/{{ .Values.postgresql.fullnameOverride }}

Then install NICo into this same namespace:

  helm upgrade --install nico deploy/charts/nico --namespace {{ .Release.Namespace }} ...
